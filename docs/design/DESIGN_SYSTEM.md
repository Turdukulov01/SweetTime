# SweetTime Design System (эталон для Flutter)

Источник: утверждённый веб-прототип `../../../sweettimetwo/` (дизайн №2, скорректирован под фичи SweetTime 2026-07-08). Прототип — макет **мобильного приложения** iOS/Android; проверять вёрстку на вьюпорте 390×844. Скриншоты эталона: [screens/d2-*.png](screens/).

## 1. Цвета

Светлая тема (по умолчанию, приоритетная):

| Роль | Токен | HEX |
|---|---|---|
| Фон | `cream-50` | `#fffaf0` (+ розовый radial-градиент сверху слева) |
| Поверхность/карточка | white 86–88% + blur | `#ffffff` @ 0.86 |
| Акцент / основная кнопка | `candy-500` | `#ff5c9a` |
| Акцент нажатие/текст-акцент | `candy-700` | `#c91f63` |
| Акцент-подложка (выбранное) | `candy-50` / border `candy-300` | `#fff1f7` / `#ff9ec6` |
| Успех / вторичная кнопка | `mint-500` / `mint-100` | `#34c99a` / `#d8f8ea` |
| Текст основной | `coffee-900` | `#251713` |
| Текст вторичный | `coffee-700` / `coffee-500` | `#4b2d22` / `#7b4b35` |
| Кремовые подложки | `cream-100` / `cream-200` | `#fff1d8` / `#ffe2ad` |

Тёмная тема (поддерживается, не приоритет): фон `#161215`, поверхность `#231d21` (white @ 0.08), текст `#fff7ee`, focus-ring `mint-300` `#8fe5c7`. Переключение — class `dark` (в Flutter — `ThemeMode`).

CSS-переменные лежат в [styles/tokens.css](../../../sweettimetwo/styles/tokens.css), палитра — в [tailwind.config.ts](../../../sweettimetwo/tailwind.config.ts).

## 2. Типографика

- Единственная семья: **Inter** (полная кириллица — во Flutter `GoogleFonts.inter`).
- Заголовки: semibold; экранные размеры: H1 36–40, H2 24–30, H3 20, тело 14, подписи/hint 12, таб-бар 11.
- Цены и коды — тот же Inter, `font-mono` только для реферального кода.
- Валюта: `1 234 сом` (пробел-разделитель тысяч, без копеек) — функция `formatCurrency` в [lib/utils.ts](../../../sweettimetwo/lib/utils.ts).

## 3. Форма и тени

- Кнопки — полностью круглые (pill, `rounded-full`); высоты: sm 36, md 44, lg 48, icon 40×40.
- Карточки — `rounded-lg` + `surface` (полупрозрачный белый, blur, бордер `coffee-900/10`).
- Тени: `soft` `0 18px 60px rgba(124,75,53,0.12)`; `glow` (акцентная) `0 0 0 1px rgba(255,92,154,0.12), 0 20px 70px rgba(255,92,154,0.18)`.
- Анимации: `float` (5s покачивание), `shimmer` (skeleton), reveal-on-scroll (во Flutter — стандартные implicit-анимации, без перегруза).

## 4. Мобильные паттерны (обязательны для Flutter)

- **Нижняя таб-навигация**: Главная / Каталог / Корзина (с бейджем количества) / Профиль — [mobile-tab-bar.tsx](../../../sweettimetwo/components/layout/mobile-tab-bar.tsx) → Flutter `NavigationBar`.
- Тап-зоны ≥ 44px (`min-h-11`/`min-h-14`).
- Выбор из 2–3 вариантов — крупные карточки-сегменты с подписью-hint (филиал, способ получения, оплата, план предоплаты) → Flutter `SegmentedButton`/карточки.
- Итог заказа — прилипающая панель у нижнего края над таб-баром.
- Никаких hover-зависимостей; состояния — цветом бордера и подложки.

## 5. Компоненты

UI-кит: Button (primary/secondary/ghost/danger), Card, Input, Badge, Skeleton, Reveal — [components/ui/](../../../sweettimetwo/components/ui/).
Доменные: ProductCard (фото/DrinkArt, бейджи «Новинка»/«Хит продаж», цена, рейтинг, «В корзину»), ProductCustomizer (размер S/M/L, лёд ×4, сахар 0–100 ×5, топпинги-чипсы), DrinkArt (SVG-заглушка напитка по цвету товара), Header, Footer, MobileTabBar.

## 6. Экраны и состояния (карта → Flutter)

| Роут прототипа | Flutter-экран | Ключевые состояния |
|---|---|---|
| `/` | Home | скрытие пустого блока акций |
| `/catalog` | Catalog | поиск, чипы категорий, пусто-«ничего не найдено» |
| `/product/[slug]` | ProductDetail | кастомизатор, рекомендации |
| `/cart` | Cart | пустая корзина; тумблер «Списать баллы (до 30%)»; строка «Начислим N баллов (5%)» |
| `/checkout` | Checkout | выбор филиала; предупреждение «напиток недоступен в филиале»; способы: самовывоз / ко времени (time picker) / QR в кафе (номер столика); оплаты: демо / наличные / QR-демо; успех «Заказ принят → Готовится» |
| `/auth` | Auth | шаг телефона (+996) → шаг OTP (демо-код 1111) → вход; ошибки инлайн |
| `/profile` | Profile | **гостевое состояние** («Войдите…»); баллы + правила; рефералка с копированием кода; конструктор «Постоянный заказ»; история (Готовится/Готов к выдаче/Выдан/Отменён); адреса; любимые |
| `/admin` | — (web-админка) | не показывается в клиентской навигации |

## 7. Бизнес-правила, зашитые в UI

- Лояльность: **1 балл = 1 сом**, начисление **5%** от оплаченной суммы, списание **до 30%** заказа, сгорание через **12 месяцев** (показываем ближайшее сгорание). Конфиг: `loyalty` в [lib/data.ts](../../../sweettimetwo/lib/data.ts).
- Рефералка: приглашённому **50**, пригласившему **100** после первого выполненного заказа; код формата `SWEET-ИМЯ`.
- Постоянный заказ: комбо из любимых напитков + время готовности + филиал + **предоплата**: разово перед заказом / неделя (×7) / месяц (×30); после оплаты показываем «оплачено до …».
- Заказы MVP: самовывоз сейчас, самовывоз ко времени, QR-заказ со столика. Доставки в MVP **нет**.
- Оплаты MVP: демо-оплата, наличные, QR-демо (реальные MBank/Элсом/О!Деньги — позже).
- Филиалы: Чуй 123, Манаса 56, ТРЦ Bishkek Park — с часами работы и списком недоступных товаров.

## 8. Что осталось на этап Flutter

- Перенести токены в `lib/core/theme` (ColorScheme + TextTheme + компонентные темы).
- Экраны прототипа → feature-модули (Riverpod), нижняя навигация — `NavigationBar`.
- Экраны, которых нет в прототипе и которые рисуем сразу во Flutter по этим токенам: Splash, Onboarding, push-настройки, удаление аккаунта, история баллов, статус заказа (пуш/поллинг).
