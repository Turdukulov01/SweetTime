## 2. На сервере (SSH): единый скрипт раскатки

```bash
set -euo pipefail

archive=/tmp/sweettime-5e9fb34.tar.gz
expected_sha=13e05fa36a870f8722ff005829c76ddd72d1511e61bfe9fd481ffcd4aee1d347
echo "$expected_sha  $archive" | sha256sum -c -

cd /srv/projects/sweetime/deploy/production

# 0) Текущая ревизия БД — ОЖИДАЕМ c19f6b4a8e21 (голова до этапа).
#    Если иное (кроме уже применённой d8e42c1a7f90) — ОСТАНОВИСЬ и разберись.
docker compose --env-file .env run --rm migrate alembic -c /app/api/alembic.ini current

# 1) Бэкап ДО миграции схемы (кратко останавливает nginx/admin/backend, потом поднимает).
./backup-production.sh
ls -la /srv/sweetime/backups/snapshots | tail

# 2) Распаковать новый код, сохранив .env (guard как в прошлый раз).
env_before="$(sha256sum .env | awk '{print $1}')"
tar -xzf "$archive" -C /srv/projects/sweetime
env_after="$(sha256sum .env | awk '{print $1}')"
test "$env_before" = "$env_after" || { echo "ОШИБКА: production .env изменился"; exit 1; }
echo "env_preserved=yes"

# 3) Валидация + сборка BACKEND и ADMIN (не только admin!).
docker compose --env-file .env config --quiet
docker compose --env-file .env build backend admin

# 4) Миграция (применит d8e42c1a7f90), затем пересоздать сервисы.
docker compose --env-file .env run --rm migrate
docker compose --env-file .env up -d --force-recreate --no-deps --wait --wait-timeout 180 backend admin
docker compose --env-file .env up -d --force-recreate --no-deps nginx
docker compose --env-file .env ps

# 5) Свежий APK для referral-лендинга (до Google Play).
install -m 644 /tmp/SweetTime.apk /srv/sweetime/downloads/SweetTime.apk
sha256sum /srv/sweetime/downloads/SweetTime.apk   # ждём 3c71119f1f57edb67d65796030b720f3f12d27694cff286d95d32ce6807cadc1

# 6) Smoke (публичный HTTPS).
base=https://lnp-corporation.duckdns.org
for p in /ready /login /api/companies/sweettime/config; do
  printf '%s -> %s\n' "$p" "$(curl -sS -o /dev/null -w '%{http_code}' "$base$p")"
done
printf '/admin -> %s\n' "$(curl -sS -o /dev/null -w '%{http_code}' "$base/admin")"       # 302
printf '/media/temp/x -> %s\n' "$(curl -sS -o /dev/null -w '%{http_code}' "$base/media/temp/x")"  # 403
echo "STAGE 2026-07-24 DEPLOYED"
```

Ожидаемо: `/ready`=200, `/login`=200, company_config=200, `/admin`=302, `/media/temp/`=403.
Если что-то не 200 — `docker compose --env-file .env logs --tail=150 migrate backend admin nginx`.

## SMTP (когда появятся реальные креды) — иначе оставляем ручную ссылку

В `.env`:

```dotenv
STAFF_INVITE_DELIVERY_MODE=smtp
SMTP_HOST=...
SMTP_PORT=587
SMTP_USERNAME=...
SMTP_PASSWORD=...
SMTP_FROM_EMAIL=no-reply@...
SMTP_SECURITY=starttls
```

Только сертификат-верифицированный STARTTLS или implicit TLS (`ssl`, 465). Затем
`docker compose --env-file .env up -d --force-recreate --no-deps backend`.
