
## 7. Ручная приёмка в браузере (RBAC + расписание)

- Owner: логин → `/staff` → пригласить manager и barista (barista привязан к филиалу);
  скопировать одноразовую ссылку (SMTP пока не настроен — это штатный fallback).
- Сотрудник открывает ссылку в приватном окне → задаёт пароль → входит.
- Manager: видит каталог/контент/все заказы; НЕ видит настройки/брендинг/команду.
- Barista: видит только очередь заказов своего филиала.
- Расписание: создать сторис/новость с будущими датой/временем → не видна до срока в приложении;
  проверить одну image и одну video публикацию на устройстве после наступления времени.

## SMTP (когда появятся реальные креды) — иначе оставляем ручную ссылку

В `.env` добавить и `docker compose up -d backend`:

```dotenv
STAFF_INVITE_DELIVERY_MODE=smtp
SMTP_HOST=...
SMTP_PORT=587
SMTP_USERNAME=...
SMTP_PASSWORD=...
SMTP_FROM_EMAIL=no-reply@...
SMTP_SECURITY=starttls
```

Поддерживается только сертификат-верифицированный STARTTLS или implicit TLS (`ssl`, порт 465).
